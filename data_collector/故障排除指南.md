# 故障排除指南 - 导出文件无效问题

## 问题现象
导出的Excel文件提示"不是一个有效的文件"或无法打开。

## 快速诊断步骤

### 步骤1：运行手动测试脚本
```bash
cd c:\works\pachong\data_collector
python 手动测试API.py
```

这个脚本会：
- 测试API连接
- 显示原始返回数据
- 检查关键字段是否正确
- 保存完整响应到 `api_response.json`

**预期结果：**
```
✓ 请求成功!

✓ data存在
  total: 5000+
  diff数组: 3 条记录

记录 1:
  代码 (f12): 000001
  名称 (f14): 平安银行
  最新价 (f2): 10.50
  涨跌幅 (f3): 2.5
  成交量 (f5): 123456
  主力净流入 (f62): 1000.5
```

如果看到以上结果，说明API工作正常。

### 步骤2：使用GUI测试连接
1. 运行 `python gui.py`
2. 切换到"资金流向"标签页
3. 点击"测试连接"按钮
4. 查看日志输出

**检查要点：**
- ✅ 是否显示"✓ API响应成功"
- ✅ 是否显示总记录数和示例数据
- ✅ 示例数据是否包含股票代码和名称

### 步骤3：检查数据抓取
1. 设置抓取页数为1（测试）
2. 点击"开始抓取"
3. 查看日志输出

**检查要点：**
- 日志是否显示"✓ 第 1 页: 提取 XX 条记录"
- 是否显示示例记录
- 字段列表是否正确

### 步骤4：检查导出文件
1. 抓取完成后，找到导出的文件
2. 查看文件大小（应该大于1KB）
3. 尝试用记事本打开（如果是xlsx文件，应该看到乱码，说明是二进制文件）
4. 用Excel打开

## 常见问题及解决方案

### 问题1：API返回数据但导出文件无效

**可能原因：**
- 数据格式不正确
- 所有字段都为空
- 文件被其他程序占用

**解决方案：**
1. 查看日志中的"字段列表"和"第一条记录"
2. 如果所有字段都为空，检查API字段映射
3. 确保文件没有被Excel或其他程序打开

### 问题2：API返回数据为空

**可能原因：**
- API接口变化
- 网络问题
- 请求被拦截

**解决方案：**
1. 运行 `python 手动测试API.py` 检查API
2. 检查网络连接
3. 尝试使用浏览器模式

### 问题3：导出文件大小为0或很小

**可能原因：**
- 数据为空
- 导出过程中出错

**解决方案：**
1. 查看日志中的"文件大小"
2. 检查日志中是否有错误信息
3. 尝试CSV格式导出

### 问题4：Excel打开文件时报错

**可能原因：**
- openpyxl库版本问题
- 数据包含特殊字符
- 文件写入不完整

**解决方案：**
```bash
# 重新安装openpyxl
pip install --upgrade openpyxl

# 或尝试CSV格式导出
```

## 调试方法

### 方法1：查看详细日志
修改 `config.yaml`：
```yaml
saver:
  log_level: "DEBUG"  # 改为DEBUG级别
```

重新运行，查看更详细的日志。

### 方法2：检查API响应文件
运行 `python 手动测试API.py` 后，打开 `api_response.json`：
- 检查 `data.diff` 数组是否存在
- 检查字段名称是否正确
- 检查字段值是否为空

### 方法3：手动验证导出
在Python控制台中：
```python
import pandas as pd
from saver import Saver

# 创建测试数据
test_data = [
    {"代码": "000001", "名称": "平安银行", "最新价": "10.50"},
    {"代码": "000002", "名称": "万科A", "最新价": "8.20"},
]

# 测试导出
saver = Saver()
output = saver.save(test_data, fmt="xlsx", filename="test")
print(f"导出文件: {output}")
```

### 方法4：检查文件权限
确保 `output` 目录有写入权限：
```bash
# Windows
icacls output

# 如果权限有问题，重新创建目录
rmdir /s output
mkdir output
```
