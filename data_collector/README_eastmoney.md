# 东方财富网资金流向数据抓取功能

## 功能概述

已集成到GUI数据采集工具中，位于"资金流向"标签页。

### 启动方式

```bash
cd c:\works\pachong\data_collector
python gui.py
```

启动后切换到"资金流向"标签页即可使用。

## 功能特性

- ✅ **自动翻页抓取** - 支持批量抓取多页数据
- ✅ **双模式支持** - API模式（快速稳定）和浏览器模式（兼容性强）
- ✅ **数据清洗去重** - 自动清理和去重数据
- ✅ **多格式导出** - 支持 Excel (.xlsx) 和 CSV 格式
- ✅ **多市场支持** - A股、沪市、深市、创业板、科创板
- ✅ **实时进度显示** - 显示抓取进度和日志
- ✅ **合规控制** - 内置请求限流和敏感字段过滤

## 使用说明

### 1. 选择市场类型
- **A股全市场** - 包含沪深两市所有股票
- **沪市** - 仅上海证券交易所
- **深市** - 仅深圳证券交易所
- **创业板** - 深圳创业板
- **科创板** - 上海科创板

### 2. 选择抓取模式

#### API模式（推荐）
- ⚡ 速度快 - 直接访问数据接口
- 🎯 稳定性好 - 不受页面结构变化影响
- 💾 资源占用少 - 无需启动浏览器
- 📊 数据完整 - 可获取更多字段

#### 浏览器模式
- 🌐 兼容性强 - 可处理复杂页面
- 适合API接口不可用时使用
- 需要安装Playwright

### 3. 设置参数
- **抓取页数** - 1-100页，每页约100条数据
- **每页数量** - API模式可设置20-500条
- **渲染等待** - 浏览器模式的页面渲染等待时间

### 4. 开始抓取
点击"开始抓取"按钮，实时查看进度和日志。

### 5. 查看结果
抓取完成后，点击"打开输出目录"查看导出的文件。

## 配置文件

可以通过 `config.yaml` 修改全局配置：

```yaml
compliance:
  request_delay_min: 1.0   # 最小请求间隔（秒）
  request_delay_max: 3.0   # 最大请求间隔（秒）

saver:
  export_format: "xlsx"    # 默认导出格式
  export_path: "output"    # 导出目录
  log_level: "INFO"        # 日志级别
```

## 故障排除

### 问题1：Python环境错误

**症状：** 运行脚本时提示 "Exit code 49"

**解决方案：**
1. 确保已安装 Python 3.9+
2. 检查Python是否在系统PATH中
3. 尝试使用 `python3` 或 `py` 命令

### 问题2：缺少依赖包

**症状：** 提示 "ModuleNotFoundError"

**解决方案：**
```bash
# 安装所有依赖
pip install -r requirements.txt
```

### 问题3：Playwright浏览器未安装

**症状：** 浏览器模式提示 "Playwright not installed"

**解决方案：**
```bash
pip install playwright
playwright install chromium
```

### 问题4：请求被限流

**症状：** 提示 "HTTP 403" 或连接超时

**解决方案：**
1. 在 `config.yaml` 中增加请求延迟
2. 减少每页数据量
3. 使用代理（需配置 `proxy_provider.py`）

## 扩展开发

### 自定义数据字段

编辑 `eastmoney_scraper.py` 中的 `EastMoneyAPI.FIELD_NAMES` 字典：

```python
FIELD_NAMES = {
    "f12": "代码",
    "f14": "名称",
    # 添加更多字段...
}
```

### 添加新的市场类型

编辑 `EastMoneyAPI.fetch_page()` 方法中的 `market_filters` 字典：

```python
market_filters = {
    "a股": "m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23",
    # 添加更多市场类型...
}
```

### 集成到其他项目

```python
from eastmoney_scraper import EastMoneyScraper

# 创建抓取器实例
scraper = EastMoneyScraper()

# 抓取数据
data = scraper.scrape_with_api(max_pages=5, market="创业板")

# 处理数据
for record in data:
    print(f"{record['代码']} - {record['名称']}: {record['涨跌幅']}")

# 导出数据
scraper.export_data(data, export_format="xlsx")

# 清理资源
scraper.close()
```
