# 资金流向抓取功能使用说明

## 功能已集成到GUI

资金流向抓取功能已完全集成到GUI工具中，无需使用额外的脚本文件。

### 启动方式
```bash
cd c:\works\pachong\data_collector
python gui.py
```

启动后切换到 **"资金流向"** 标签页。

## 使用步骤

### 1. 测试API连接（重要！）
首次使用前，建议先测试API是否正常：
- 点击 **"测试连接"** 按钮
- 查看日志输出，确认API返回数据正常
- 如果测试成功，说明API工作正常

### 2. 设置抓取参数
- **市场类型**：选择A股、沪市、深市、创业板或科创板
- **抓取模式**：
  - **API模式（推荐）**：速度快，直接访问数据接口
  - **浏览器模式**：需要安装Playwright，适合API不可用时
- **抓取页数**：1-100页，每页约100条数据
- **每页数量**：API模式可设置20-500条
- **导出格式**：Excel (.xlsx) 或 CSV

### 3. 开始抓取
- 点击 **"开始抓取"** 按钮
- 实时查看进度和日志
- 等待抓取完成

### 4. 查看结果
- 抓取完成后点击 **"打开输出目录"**
- 文件名格式：`eastmoney_市场_时间.xlsx`

## 数据字段说明

抓取的数据包含以下字段：
- **基本信息**：代码、名称
- **价格数据**：最新价、最高、最低、今开、昨收
- **行情数据**：涨跌幅、涨跌额、成交量、成交额、振幅、换手率
- **资金流向**：
  - 主力净流入、主力净比
  - 超大单净流入、超大单净比
  - 大单净流入、大单净比
  - 中单净流入、中单净比
  - 小单净流入、小单净比

## 常见问题

### Q: 为什么抓取的数据是空的？

**可能原因和解决方法：**

1. **网络连接问题**
   - 检查网络连接是否正常
   - 点击"测试连接"验证API是否可访问

2. **API接口变化**
   - 东方财富可能更新了API接口
   - 点击"测试连接"查看具体错误信息
   - 如果测试失败，尝试使用浏览器模式

3. **防火墙/代理问题**
   - 检查防火墙是否拦截了请求
   - 如果使用代理，确保代理配置正确

4. **市场选择问题**
   - 某些市场可能在特定时间没有数据
   - 尝试选择"A股全市场"

### Q: 如何使用浏览器模式？

浏览器模式需要安装Playwright：

```bash
# 安装Playwright
pip install playwright

# 安装浏览器驱动
playwright install chromium
```

安装完成后重启GUI，即可使用浏览器模式。

### Q: 抓取速度慢怎么办？

- **使用API模式**：比浏览器模式快10倍以上
- **减少页数**：先测试少量页数，确认数据正常
- **调整请求间隔**：修改config.yaml中的`request_delay_min`和`request_delay_max`

### Q: 数据去重是如何工作的？

工具会自动根据"代码"和"名称"字段去除重复记录，确保每只股票只出现一次。

## 技术细节

### API模式
- 直接访问东方财富网的数据接口
- URL: `https://push2.eastmoney.com/api/qt/clist/get`
- 完整字段列表：f1,f2,f3,f4,f5,f6,f7,f8,f9,f10,f12,f13,f14,f15,f16,f17,f18,f20,f21,f23,f24,f25,f22,f11,f62,f128,f136,f115,f152

### 浏览器模式
- 使用Playwright渲染页面
- 自动解析页面表格数据
- 适合API不可用或页面结构复杂的情况

## 注意事项

1. **合规使用**：请遵守网站使用条款，合理设置请求频率
2. **数据准确性**：抓取的数据仅供参考，请以官方数据为准
3. **请求频率**：工具内置了请求限流，避免过度请求
4. **数据时效性**：资金流向数据实时变化，建议定时抓取
